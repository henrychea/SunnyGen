Self-hosting

A self-hosted AI image generator that keeps your library on disk

SunnyGen runs on your machine. Projects, renders, references, and encrypted provider keys live in a local folder, and generation goes straight to the provider accounts you own.

Quick startView on GitHub

Why self-host your image generation

  • No account. There is no sign-up and no login to a SunnyGen service.
  • No shared credit pool. You pay each provider directly, at its own price, with no markup.
  • No telemetry. The app talks only to the providers you configure.
  • Boring storage. A SQLite database and content-addressed media files, with no cloud bucket.
  • Hackable. Small TypeScript packages in a MIT-licensed monorepo.

What stays on your machine

What Default location
Database data/sunnygen.db
Media: uploads, references, renders data/media/
Master key for encrypted API keys data/secrets.key

Move them with SUNNYGEN_DATA_DIR and SUNNYGEN_MEDIA_DIR. Provider and assistant keys are encrypted in SQLite with AES-256-GCM. Set SUNNYGEN_SECRET to supply the master key yourself.

Library tools

Uploads and imported references are deduplicated by SHA-256 and streamed with byte-range support. Social post links can be imported through an optional local cobalt container; without it, the rest of the app keeps working.

Bring your own API keys

Connect the providers you already pay for. If the selected provider is not configured, SunnyGen falls back to another configured provider that supports the same model.

Run it where you work

On your network

The ./sunnygen launcher prints local, LAN, Tailscale, and MagicDNS URLs, and can publish a Bonjour name so phones and other laptops can connect. ./sunnygen --tunnel starts a Cloudflare Tunnel connector.

As a service or in Docker

./sunnygen --install-service registers a login service that restarts after a crash: launchd on macOS, systemd --user on Linux. A root Dockerfile builds a production image that serves on port 8977 with the data directory mounted from the host.

As an app on desktop and mobile

SunnyGen is an installable PWA with a standalone window and a cached shell, so the interface opens even when the server is unreachable.

SunnyGen has no login. If you expose it beyond localhost or your private network, put an authenticating proxy in front of it, for example Cloudflare Access.
