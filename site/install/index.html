Quick start

Install SunnyGen in four commands

You need Node.js 22.20 or newer (24 recommended) and pnpm 9.15. Docker is optional.

Install and start

git clone https://github.com/henrychea/SunnyGen.git
cd SunnyGen
pnpm install
./sunnygen

The launcher builds when the source is newer than the last build and serves on 0.0.0.0:8977. Open http://localhost:8977.

Your first render

  1. Settings → Providers. Add a Sunra.ai, fal.ai, Azure, or Codex credential.
  2. Canvas. Connect a Prompt node to a Generate node and press Run all.
  3. Gallery. Every finished render lands here automatically.

Prefer hot reload while you hack on it? Run pnpm dev.

Run options

Reach it from other devices

./sunnygen --name studio     # http://studio.local:8977
./sunnygen --port 3000
./sunnygen --background      # detach, log to .sunnygen/
./sunnygen --tunnel          # Cloudflare Tunnel connector

The launcher prints local, LAN, Tailscale, and MagicDNS URLs.

Keep it running as a service

./sunnygen --install-service
./sunnygen --service-status
./sunnygen --restart-service

This uses launchd on macOS and systemd --user on Linux, and restarts the app after a crash.

Run it in Docker

docker compose -p sunnygen-prod up -d --build

The image serves on port 8977 and mounts the data directory from the host.

Install as an app

  • Chrome or Edge: use the install icon in the address bar.
  • iPhone or iPad (Safari): Share → Add to Home Screen.
  • Android (Chrome): Menu → Install app.

Optional extras

Social imports need a local cobalt container: ./sunnygen --cobalt. The Codex provider needs the codex CLI logged in on the same machine. Environment fallbacks for keys: SUNRA_API_KEY, FAL_KEY, AZURE_API_KEY, OPENROUTER_API_KEY.

SunnyGen has no login. Before you expose it beyond your private network, put an authenticating proxy such as Cloudflare Access in front of it.
