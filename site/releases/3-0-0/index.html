SunnyGen 3.0.0

A dark theme, an NSFW mode that unlocks uncensored providers, and a video copy pipeline that turns a reference clip into a shot list and a joined remake.

  • 2026-11-26
  • Migrations 5 and 6
  • ffmpeg for video copy
  • NSFW mode off by default

Dark theme

Settings → Theme offers System, Light and Dark. The choice is stored in the browser and applies per device, so the phone and the desktop can differ. A small script sets the palette before the first paint, so a dark device never flashes the light theme while the app loads, and the browser chrome colour follows.

Dark is a second token set under the same variables the light theme uses, not a set of per-component overrides, so every route and every dialog follows without a second stylesheet.

NSFW mode and uncensored providers

NSFW mode is a switch in Settings, off by default, remembered per device. While it is on, SunnyGen writes the least restrictive documented value for every safety field the chosen provider endpoint exposes, and it opens the uncensored models. While it is off, requests carry exactly the fields they carried before, so nothing changes for an install that never turns it on.

Visibility is a server rule, not a blur. Generations and assets made in NSFW mode are marked, and safe mode removes them in SQL, so the rows never reach the browser and the media route answers 404. Frames and joined clips made by the video copy pipeline inherit their source's flag, and a copy of an NSFW clip is hidden with it.

The local provider talks to a stable-diffusion.cpp sd-server that you run yourself; SunnyGen never installs or starts it. Both providers exist only while NSFW mode is on.

Video copy pipeline

The Video tab has a Copy panel beside Generate and Edit. It rebuilds a reference clip as your own generation instead of guessing one prompt for the whole video.

  1. Extract frames. Pick a source clip of 600 seconds or less and pull up to 48 stills by scene change, by interval, or at exact timestamps.
  2. Edit a frame. Any still opens in the existing image editor, so a costume or a background changes before the plan is written.
  3. Read a shot list. Claude Code, Codex, OMP or Pi reads the stills and returns a schema-checked shot list, or you paste one and edit it by hand.
  4. Generate and join. Each shot renders through the existing start-and-end-frame video mode, up to 24 shots, then Join concatenates the finished clips into one new asset.

The work is stored as it goes, so a reload resumes at the stage it reached. Joining stream-copies only when every clip shares its codec, size and frame rate, and re-encodes otherwise. The rest of the app runs without ffmpeg; this panel says what to install when it is missing.

UI cleanup

Every surface, both palettes, was audited against one written standard and the findings were fixed:

  • One muted text tier above the WCAG AA contrast floor replaced six opacity steps that failed it.
  • Container borders use a stronger line token, and the warning colour passes AA in the light theme.
  • Shadows stay on dialogs, menus, toasts, panels and the assistant button; cards lost theirs.
  • No blur, no uppercase micro-labels, no list entrance animation, and no text below 11px.
  • Touch pointers get 44px targets, and two hand-rolled dialogs gained focus containment.

Upgrading

Back up data/sunnygen.db before the first 3.0.0 start. Migrations 5 and 6 run automatically, and there is no down-migration.

  • Migrations. 5 adds an nsfw flag to generations and assets with a safe default, so every existing render stays visible. 6 adds the video copy table.
  • ffmpeg. The video copy panel needs ffmpeg and ffprobe on PATH: apt install ffmpeg or brew install ffmpeg. The Docker image ships both.
  • Agent CLIs are optional. Shot-list analysis uses claude, codex, omp or pi when one is installed and logged in; without one, paste a shot list.
  • Two per-device modes. NSFW mode is a cookie and the theme is browser storage. Neither is written to the database, and clearing site data returns an install to safe mode and System theme.
