# Dark Theme Implementation Plan

> **For agentic workers:** Executed by Orca Pi workers, one task per worker, in
> dependency order: Task 1 → Task 2 → Task 3 → (Task 4 ∥ Task 5) → Task 6 → Task 7.
> Steps use checkbox (`- [ ]`) syntax for tracking. Workers other than Task 1 must wait
> for the tasks they consume.

**Goal:** Ship a dark theme selected as System / Light / Dark in Settings, with no flash of the wrong theme, warm near-black tokens, an accent that passes WCAG AA on dark, and every hardcoded colour and shadow in `apps/web/src` and `packages/ui/src` replaced by a token.

**Architecture:** Keep the existing `@theme` block as the light default and add a second token block keyed on `html[data-theme='dark']`. Tailwind v4 already compiles every utility to `var(--color-*)`, so the override re-themes the whole app with no component fork. A dependency-free inline script in `<head>` resolves System / Light / Dark from `localStorage` plus `prefers-color-scheme` and sets the attribute before first paint.

**Tech Stack:** Tailwind CSS 4 (`@theme`, `@tailwindcss/vite`), TanStack Start root document, React 19, `tsx --test`.

**Spec:** `docs/superpowers/specs/2026-11-25-v3-release-design.md` (section 1)

## Global Constraints

- **Do not commit.** Leave every change in the working tree and report; the coordinator
  asks the owner before any commit.
- **Do not start or stop dev servers for verification unless the task says so.** Tasks 3
  and 7 need the demo server; use `pnpm dev:demo` (port 8978) and stop it when done.
  Never touch `data/sunnygen.db`, never the Docker `sunnygen-prod` container.
- **No AI attribution** anywhere; no code comments unless logic demands one.
- Theme classes only (`bg-canvas`, `text-ink`, `border-line`, `bg-accent`). New code
  never writes a hex value.
- Use `html[data-theme='dark']` for the override, not `:root` or `[data-theme]`. The
  compiled variables land on `:root,:host` at specificity (0,1,0); the element selector
  (0,1,1) wins without `!important`.
- Every value below is already contrast-checked. Do not "improve" a hex without running
  `python3 ~/.claude/skills/antislop-human/contrast-check.py <text> <background>` and
  reporting the ratio.
- Unit tests are `tsx --test` files beside the code, `*.test.ts`.

### Task 1: Theme resolution module

**Files:**

- Create: `apps/web/src/lib/theme.ts`
- Test: `apps/web/src/lib/theme.test.ts`

**Interfaces:**

- Consumes: nothing.
- Produces (exact, used by Tasks 2, 3, 4, 6):
  - `THEME_STORAGE_KEY = 'sunnygen.theme'`
  - `type ThemeMode = 'system' | 'light' | 'dark'`
  - `type ResolvedTheme = 'light' | 'dark'`
  - `parseThemeMode(value: string | null): ThemeMode` — anything that is not `'light'`
    or `'dark'` returns `'system'`.
  - `resolveTheme(mode: ThemeMode, systemPrefersDark: boolean): ResolvedTheme`
  - `readStoredTheme(storage: Pick<Storage, 'getItem'> | null): ThemeMode` — returns
    `'system'` for null storage or a storage that throws.
  - `applyTheme(mode: ThemeMode, root?: HTMLElement, systemPrefersDark?: boolean): ResolvedTheme`
    — writes `root.dataset.theme` and returns the resolved value.
  - `systemPrefersDark(): boolean`
  - `startThemeSync(): () => void` — applies the stored mode now, re-applies on
    `prefers-color-scheme` change when the mode is `'system'`, returns the cleanup.
  - `THEME_BOOT_SCRIPT: string` — an IIFE, no imports, no optional chaining, wrapped in
    `try/catch`, that reads the key, resolves `'light' | 'dark'`, and sets
    `document.documentElement.dataset.theme`.

  assert.equal(parseThemeMode('light'), 'light')
  assert.equal(parseThemeMode('system'), 'system')
  assert.equal(parseThemeMode('DARK'), 'system')

  assert.equal(resolveTheme('system', true), 'dark')
  assert.equal(resolveTheme('system', false), 'light')
  assert.equal(resolveTheme('dark', false), 'dark')
  assert.equal(resolveTheme('light', true), 'light')
})

test('readStoredTheme survives missing and throwing storage', () => {
  assert.equal(readStoredTheme(null), 'system')
  assert.equal(readStoredTheme({ getItem: () => 'dark' }), 'dark')
  assert.equal(
    readStoredTheme({
      getItem: () => {

      },
